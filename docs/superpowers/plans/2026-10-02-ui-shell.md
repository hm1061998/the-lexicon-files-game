# Vỏ ngoài game (tiêu đề, chọn hồ sơ, các bước phụ, tạm dừng, briefing, tổng kết) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đưa chín màn ngoài lúc chơi về ngôn ngữ "hồ sơ trinh thám trên mặt bàn": nền gỗ, bìa hồ sơ + tab chia mục, tờ giấy modal; chỉ đổi trình bày.

**Architecture:** Vật liệu mới sinh bằng code trong `tools/art-codegen`; bốn primitive dùng chung trong `packages/ui` (`DeskBackdrop`, `FolderCover`, `FolderTabs`, `ModalSheet`) cộng biến thể màu cho `Stamp`; các màn trong `apps/game-web` chỉ lắp nội dung. `titleModel`, stage, store, phím tắt, focus trap giữ nguyên.

**Tech Stack:** TypeScript strict, React 18, Vitest, Playwright, Python (numpy + Pillow) trong `.venv-art-codegen`; npm + Nx.

**Spec:** `docs/superpowers/specs/2026-10-02-ui-shell-design.md` (đã duyệt 02/10/2026).

## Global Constraints

- Chỉ npm + Nx; không thêm dependency. Node 22; Python qua `.venv-art-codegen/Scripts/python` (`python -m pytest tools/art-codegen -q`).
- Chữ tối thiểu 14px; Xanh Mono (tiêu đề/con dấu) không dưới 18px; Patrick Hand ≥ 18px. Mục tiêu bấm ≥ 44×44, focus `--lexicon-focus` (3px, offset 3px).
- Bóng: blur ≤ 6px, alpha ≤ 25%. Chuyển động: giấy/bìa vào 160–220ms, con dấu 180ms; không rung, không nhấp nháy; tắt khi setting giảm chuyển động hoặc `prefers-reduced-motion`.
- Đỏ `#A4412D`/`#743026` chỉ cho clue/evidence/objective/contradiction/selected/map marker; trong plan này **chỉ con dấu CASE CLOSED** dùng đỏ (AGENTS.md §6). Không điểm số, xếp hạng, timer, "WRONG!".
- Không đổi `game-core`, `learning-engine`, save version, Condition/Effect, event bus, `titleModel`, phím tắt, điều kiện khóa input. Text hiển thị lấy từ UI strings (`packages/game-content/ui/vi.json` + `schema/ui.ts`) hoặc content.
- Giữ tên nút/role/class mà E2E dùng: `.title-card`, `.title-card button`, `.pause-menu`, `.briefing-memo`, `.briefing-line`, `.briefing-accept`, `.case-card`; nút "Vụ án mới", "Tiếp tục điều tra", "Dùng mặc định", "Bắt đầu lại", "Nhận hồ sơ".
- `PaperPanel` giữ nguyên cho dialogue/evidence/notebook (phần 4–5): không xóa.
- Mỗi task một commit nhỏ; `git add` đường dẫn cụ thể; không push (chờ người dùng). Spec/plan/báo cáo tiếng Việt; báo cáo: `docs/ai/2026-10-02-ui-shell-verification.md` (tạo ở Task 0).
- Môi trường: sửa file bằng Edit/Write hoặc Python giữ nguyên newline (working copy CRLF, HEAD LF); không sửa mã nguồn trong lúc E2E đang chạy (HMR làm nhiễu); sau mỗi lần chạy E2E chạy `git checkout docs/ai/playtests` cho ảnh bị spec ghi đè và xóa `docs/ai/playtests/2026-10-02-intro-onboarding`.

| Loại | Giá trị |
| --- | --- |
| Texture mới (`apps/game-web/public/assets/ui/`) | `desk_wood.png` 512×512 lát liền; `folder_cover.png` 320×240, slice 48; `folder_tab.png` 160×64, slice 20; `scrim_vignette.png` 256×256 chỉ alpha |
